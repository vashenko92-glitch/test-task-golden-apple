# Тестовое задание: аналитик данных (ценообразование)

Решение задач по алгоритмам ценообразования, продуктовой аналитике
и написанию SQL-запросов.

## Стек технологий

- Python
- ClickHouse (SQL)
- Jupyter Notebook

```text

```
